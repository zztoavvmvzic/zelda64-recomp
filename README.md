## Overview

Zelda64 Recomp uses automated N64 recompilation technology to transform Majora's Mask into a native PC executable, delivering the exact original gameplay at any resolution and framerate without emulator overhead. It requires a legally obtained Majora's Mask ROM and provides a modern platform for the Zelda modding community with ZIP-based mod loading for texture packs, audio replacements, and gameplay mods.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Zelda64 Recomp** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Native PC Execution** | Recompiled native binary runs without any N64 emulator overhead |
| **Any Resolution** | Widescreen, ultrawide (21:9/32:9), and 4K rendering with correct HUD |
| **Unlocked Framerate** | Uncapped framerate with physics and timing interpolation |
| **Mod Support** | ZIP-format mod loading for texture packs, audio, and gameplay changes |
